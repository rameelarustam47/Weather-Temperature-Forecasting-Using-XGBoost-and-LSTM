# Weather Temperature Forecasting Using XGBoost and LSTM

## 📌 Project Overview

This project focuses on **short-term temperature forecasting using Machine Learning and Deep Learning**.

I personally collected **63 weather observations in Faisalabad, Pakistan**, from **3 August to 23 August 2026**. The observations include temperature, humidity, rain occurrence, date, time, and observation period (Morning, Noon, or Evening).

The collected data was used to develop and compare **XGBoost** and **LSTM** models for forecasting the next temperature reading.

## 🎯 Objective

The main objective of this project is to:

* Develop a short-term temperature forecasting model using self-collected weather observations.
* Compare **XGBoost** and **LSTM** forecasting approaches.
* Evaluate model performance using **MAE, RMSE, and R²**.
* Forecast the next unseen temperature observation.

## 📊 Data Collection

The dataset was **personally collected by me** in Faisalabad, Pakistan.

A total of **63 weather readings** were recorded between **3 August and 23 August 2026**.

Each observation contains:

* Date
* Observation time
* Period: Morning / Noon / Evening
* Temperature (°C)
* Humidity (%)
* Rain flag

The dataset is based on my own field observations rather than a downloaded public dataset.

## ⚙️ Methodology

### 1. Data Preparation

The observations were organized chronologically and processed using Python and Pandas.

### 2. Feature Engineering

The following features were developed:

* Temperature
* Humidity
* Rain flag
* Hour of observation
* Cyclical hour features (`hour_sin`, `hour_cos`)
* Lagged temperature values
* 3-reading rolling temperature average
* Observation-period indicators

### 3. XGBoost Model

An **XGBoost regression model** was developed to forecast the next temperature reading using weather and temporal features.

### 4. LSTM Model

An **LSTM (Long Short-Term Memory)** neural network was developed to learn temporal patterns from sequences of previous temperature observations.

A **6-reading lookback window** was used for the LSTM model.

### 5. Baseline

A persistence baseline was also calculated by using the current temperature as the prediction for the next reading.

## 📈 Model Evaluation

The models were evaluated using:

* **MAE — Mean Absolute Error**
* **RMSE — Root Mean Squared Error**
* **R² — Coefficient of Determination**

## 🔮 Forecasting

After model training and evaluation, both XGBoost and LSTM are used to generate a forecast for the **next unseen temperature reading**.
